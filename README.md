# Jyoti & Vaibhav — Public Wedding Invitation

This is the **public, guest-facing** wedding invitation website for 4–5 December 2026 in Nashik.

It is **not** the private operational wedding dashboard at `/JV/`. Do not add private guest lists, budgets, vendor details, or internal planning data here.

## Schedule

- Friday 4 December, 4:00 PM — Wedding Carnival
- Friday 4 December, 8:00 PM — Engagement & Sangeet
- Saturday 5 December, 12:00–5:00 PM — Pheras
- Saturday 5 December, 8:00 PM — Reception, Swaminarayan Banquet Hall, Panchavati, Nashik

Reception directions: https://maps.app.goo.gl/tUULMt9mxJoBoh8c6

## Site files

A complete, tested copy of this site is available in the `Jyoti_Vaibhav_Public_All_Events_Website.zip` package created in ChatGPT. The source contains:
`index.html`, `styles.css`, `app.js`, `config.js`, `assets/`, and `.nojekyll`.

**Initial setup:** extract the ZIP and upload its contents (not the ZIP itself) to this repository. After that, routine schedule changes can be made directly in ChatGPT via the connected GitHub app.

Site URL once GitHub Pages is enabled for `main` / root:
https://tiwarisagar2910-lab.github.io/jyoti-vaibhav-invite/

## Update policy

- Event schedule and confirmed venue details: `config.js`
- Appearance and text: `styles.css` and `index.html`
- Event cards and behavior: `app.js`
- Artwork: `assets/`

The three non-reception venues are intentionally unspecified until confirmed.
